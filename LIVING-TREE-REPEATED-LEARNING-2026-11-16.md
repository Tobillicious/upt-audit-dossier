## Mathematical result
The existing Joker interface `JokerExperiment T FiniteObjectiveU H` provides model enactment, completed-history observation and theory revision. A new `LivingTree T H E` contains a generation index, current theory, modeled complete-W source, accumulating ancestor records, arbitrary indexed ethical record values and handedness.

For each `cultivate` step:
1. Read the completed history of the **current modeled whole** `s.whole`.
2. Revise the current theory using that observation.
3. Prepare the next modeled complete source using the already-defined `objectiveStep (J.enact nextTheory)`.
4. Append the previous theory, complete source and observed history to the ancestral record.
5. Increase the epoch and carry the indexed ethics data and handedness unchanged.

- `each_generation_learns_and_prepares_next_U`

In the constructed model, the ancestral list length equals the starting length plus the number of completed cultivation steps. Every ancestor record survives arbitrarily many further finite steps. The epoch advances forward, and each successor source is computed from its newest revised theory.
